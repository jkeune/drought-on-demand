# drought-on-demand

Script collection for on-demand creation of data and plots using ERA5-Drought (Keune et al., 2025).

## Content
This repository contains 
- several on-demand jupyter notebooks (e.g., `Iceland2024.ipynb`, `Morocco.ipynb`) to create requested data & plots
- `drought-watch-live` contains a mini-webpage ([**DroughtWatch**](https://sites.ecmwf.int/nejk/drought-watch-live/)) that features the latest snapshots from ERA5-Drought, as well as scripts to produce those (`update_timeseries.py` and `update_maps.py`)
- tools to plot **drought stripes** (`drought_stripes`) on demand. 

## References
- Keune, J., Di Giuseppe, F., Barnard, C. et al. ERA5–Drought: Global drought indices based on ECMWF reanalysis. Scientific Data 12, 616 (2025). [https://doi.org/10.1038/s41597-025-04896-y](https://doi.org/10.1038/s41597-025-04896-y).
