DroughtWatch

About DroughtWatch

DroughtWatch provides regularly updated visualizations of global and regional drought conditions. It combines standardized drought indices with temporal summaries to track the evolution and intensity of drought conditions across time and space.

Data Sources

The underlying data are coming from Keune et al. (2025), published as ERA5-Drought. ERA5-Drought is based on meteorological reanalyses (ERA5) used to compute the Standardized Precipitation Index (SPI) and Standardized Precipitation Evapotranspiration Index (SPEI). These indices are widely used to assess meteorological drought conditions on multiple timescales.

What the Maps Show

Each map illustrates the current state of drought (or wetness) for the selected region and accumulation period. Negative values indicate dry conditions, while positive values represent wet anomalies. Longer time windows (e.g. 12–48 months) reflect more persistent droughts or pluvial periods.

How to Use This Tool

  • Choose Maps to visualize spatial drought anomalies.
  • Choose Timeseries to view temporal drought evolution for a given region.
  • Use the dropdown menus to select the drought index, region, and accumulation period.

When to expect updates

We only show the most recent monthly snapshots from ERA5-Drought. To ensure timeliness, we use the ERA5T release, and figures here are updated 1-2 days after the publication of the ERA5T moda stream. Updates are thus performed on the 7th of each month and show the drought anomaly of the previous month (or accumulated over the preceeding n months, always using ERA5 over ERA5T where possible).
